# DriveVault Car Studio

Интерактивті көлік таңдау, **шынайы физикалы драг-жарыс** және YouTube Shorts-ке арналған **видео жазу**.

## Іске қосу

```powershell
python -m http.server 4173
```

Браузерде `http://localhost:4173` ашыңыз (Chrome/Edge ұсынылады).

## Жарыс қалай жұмыс істейді

- **Физика** (`physics.js`): қозғалтқыш қуат қисығы, беріліс қорапшасы мен ауыстыру уақыты, доңғалақ тартылуы (AWD/RWD/FWD/MR, салмақ ауысуы), аэродинамика (CdA), домалау кедергісі. Әр көлік каталогтағы 0–100 уақытына калибрленеді, ал ¼ миля уақыты мен мәредегі жылдамдық а.к./салмаққа байланысты физикадан шығады (мысалы Plaid ≈ 9.4 с, Camry ≈ 14 с).
- **Старт**: драг-светофор 3 · 2 · 1 · GO, әр көліктің кездейсоқ реакция уақыты (RT), мәре сызығында интерполяциямен нақты уақыт, жеңімпаз = мәрені бірінші кесіп өткен.
- **Көрініс** (`render.js`): перспективалық драг-жолақ, жылдамдыққа сай камера тербелісі, тайған доңғалақ түтіні мен іздері, тежеу оттары, соңғы метрлерде slow-motion.
- **Дыбыс** (`audio.js`): rpm-ға байланысты қозғалтқыш (электромобильдерге ызың), беріліс ауыстыру, светофор сигналдары.

## Видео жазу (Shorts)

1. Көліктерді таңдап, пішімді **YouTube Shorts · 9:16 · 1080×1920** қалдырыңыз.
2. **🎬 ЖАРЫС + ВИДЕО ЖАЗУ** басыңыз — бүкіл жарыс (~25 с) автоматты жазылады, қойындыны ашық ұстаңыз.
3. Видео дайын болғанда жүктеп алып, дайын атау/сипаттаманы көшіріп, YouTube-қа жүктеңіз.

YouTube-қа автоматты жүктеу үшін Google OAuth қолданбасы қажет, сондықтан жүктеу қолмен жасалады.

## Нақты көлік суреттері

Әдепкіде екі жалпы сурет қолданылады. Нақты модель үшін артқы 3/4 көріністі мөлдір PNG салыңыз: `assets/cars/porsche-911-turbo-s.png` және `assets/cars/index.json` ішіне `["porsche-911-turbo-s"]` деп тіркеңіз (атау: `марка-модель`, кіші әріп).

## YouTube-қа тікелей жүктеу (аккаунт таңдаумен)

Видео жазылған соң «🔐 Google аккаунт таңдап жүктеу» түймесі Google-дың аккаунт таңдау терезесін ашады, сіз керек арнаны таңдайсыз да, видео сол арнаға автоматты жүктеледі (атауы, сипаттамасы, «AI Simulation / өзгертілген мазмұн» белгісімен). Бірнеше аккаунт болса, әр жолы қалаған аккаунтты таңдайсыз.

**Бір реттік баптау (≈5 минут):**
1. [console.cloud.google.com](https://console.cloud.google.com) → жаңа жоба жасаңыз.
2. «APIs & Services → Library» → **YouTube Data API v3** → Enable.
3. «OAuth consent screen» → External → аты мен email-ді толтырыңыз → «Test users» ішіне өзіңіздің барлық Google email-деріңізді қосыңыз (бірнеше аккаунт болса, бәрін).
4. «Credentials → Create credentials → OAuth client ID» → түрі **Web application**.
   «Authorized JavaScript origins» ішіне сайттың адресін қосыңыз (`https://nk89icloud-wq.github.io` — тек осы, жолсыз, соңында `/` жоқ; жергілікті тексеру үшін қосымша `http://localhost:4173`).
5. Шыққан **Client ID** (`…apps.googleusercontent.com`) мәнін сайттағы «⚙ Client ID баптау» түймесі арқылы қойыңыз. Ол тек сіздің браузеріңізде сақталады.

**Білу керек:**
- Google тексермеген (unverified) жобадан жүктелген видеолар YouTube-та алдымен «Жеке» (private) болып шығады. Studio-да «Ашық» етіп өзіңіз ауыстырасыз (немесе Google-дан API аудитін сұрайсыз).
- Күндік квота шектеулі: бір видео шамамен 1600 ұпай, әдепкі квота 10 000, яғни күніне ~6 видео.
- Google аккаунтыңызда YouTube арнасы болуы керек.

## 🏆 Турнир (ұзақ видео, YouTube-қа ашық жүктеледі)

«Турнир» бөлімінде тақырып таңдап (аралас, Қытай, Жапония, электр, суперкар...) «Турнир жасап, YouTube-қа жүктеу» түймесін басыңыз:

- 8 көлік таңдалады (қуаты жақын, бір маркадан ең көбі 2, бұрын қолданылмаған).
- Әр көлікке бірегей ерекшелік беріледі (Most Powerful, Featherweight, Instant Torque, All-Wheel Grip ...), ол таныстыруда, жарыс алдында және жарыс кезінде төменгі жолақта көрінеді.
- 7 жарыс: 4 чвертьфинал, 2 жартылай финал, финал. Нәтиже физикадан шығады.
- Бір видеоға жазылады (~6 минут, 16:9), сипаттамасында тараулар (chapters) бар, Google-да бір рет «Allow» басасыз, видео **ашық** жүктеледі.
- Видеодағы мәтін ағылшынша (АҚШ аудиториясы үшін), атауында «AI Simulation» бар.
- Тексеру үшін `?dry=1` қосып ашсаңыз (мыс. `http://localhost:4173/?dry=1`), Google-сыз жазып көруге болады (жүктелмейді).

### Турнир форматтары және баптаулар

- **Формат:** нокаут (8 көлік, 7 жарыс), әлсіздер vs күштілер, таудың королі, 8 көлік бір уақытта (бір жарыс + подиум), чемпионат (8 көлік бір уақытта, 4 жарыс, ұпай), уақыт машинасы (бір көліктің 8 жылғы нұсқасы).
- **Тақырып:** аралас, бірдей класс, спорткарлар, суперкарлар, Қытай/Жапония/Германия/Америка/Корея/Еуропа/КСРО, электрлер, SUV, седан, хэтчбек, купе, пикап, универсал.
- **Көліктерді өзгерту:** алдын ала көрінетін 8 көліктің әрқайсысының өрісіне өз көлігіңізді жазып (Enter) ауыстыруға болады. «Қайта таңдау» түймесі жаңа жиынтық алады.
- **Жол ұзақтығы:** 201 / 402 / 805 / 1000 м (чемпионатта 4 түрлі қашықтық автоматты).
- Көліктің тұсындағы түстер мен атаулар видеода да, кестеде де бірдей болады, сондықтан шатаспайды.
